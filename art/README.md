# art/ 字灵立绘

Gemini 画好的字灵立绘放在这里，网页会自动用它替换程序画的小怪兽（写字页右上角的吉祥物、卡片弹窗）。

- 文件名：`<字>_<星级>.webp`，例如 `山_1.webp`、`山_2.webp`、`山_3.webp`、`b_2.webp`。
- 尺寸：512×512，透明背景，WebP（每张 20 到 40 KB）。
- 放好文件后运行 `python tools/pack_art.py`，它会把 PNG 转成 WebP 并重写 `manifest.json`（网页靠这个清单知道哪些字有图，没有的继续用程序怪兽）。
- 提示词在 `设计/prompts_一年级.csv`，美术规范在 `设计/字灵卡美术方案.md`。
